# dsh-inject 验证记录

## 验证环境

隔离 `dsh-e2e` 实例（`dsh-base + dsh-web-app + dsh-inject`，独立 home，动态端口）。

## 自动化测试

`npm test`（12 项，全绿）：

- 角色筛选替换、正则替换、system/developer 不被改写
- 构造消息的角色映射（system / tool -> 请求侧安全角色）
- 请求前缀插入：system 保持首位并与原 system 合并；无 system 时前缀置顶
- 会话状态：默认空、按会话隔离、禁用后无残留、待注入只消费一次、超上限拒收、会话结束时清空

## 宿主路由（curl 实测）

| 请求 | 结果 |
| --- | --- |
| `text/plain` 简单请求（旧版手写校验） | 403 |
| JSON + 跨源 `Origin`（旧版手写校验） | 403 |
| 无浏览器凭据的同源 JSON（改用 `connection.admit` 后） | **401** |
| 浏览器内已鉴权请求 | 200，`已插入 1 条` |
| `GET` | 405 |
