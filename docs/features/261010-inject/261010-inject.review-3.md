# dsh-inject 第三轮检视报告

## 概要

本轮检视针对客户端架构演进：将现场注入 dialog 从 composer 输入栏右侧的常驻按钮（`conversation.input.right`）迁移至命令装饰驱动模式。变更包括：通过 `ctx.commandUi.decorate` 装饰 `/inject-turn` 的裸调用、将 dialog 注册到 `conversation.input.overlay` 插槽、抽离 `dialog-state.js` 维护会话级开关与监听集合，并更新宿主命令错误提示与使用文档。

整体评价：设计优雅、完全契合 DSH 的 client-ui-commands 与 overlay 规范（与官方 `ui-message-feedback` 的 `/feedback` 装饰及 `conversation.input.overlay` 模式高度一致），输入栏不再放置常驻冗余按钮，架构职责清晰，无内存泄漏与闭包陈旧风险。

## 架构与实现检视

### 1. decorate 与 overlay 契约对齐
- **CommandUiContract 对齐**：在 [src/client/index.jsx:55-59](src/client/index.jsx#L55-L59) 中调用 `ctx.commandUi.decorate`，传入 `{ name: "inject-turn", available: () => true, ui: { kind: "action", run: session => dialogs.open(String(session.sessionId)) } }`。完全符合 `@deepseek-ai/dsh-client-ui-commands` 定义的 `CommandDecoration` 与 `ActionSpec` 契约，`run` 回调参数为 `ClientSessionContext`，其 `sessionId` 属性被正确提取并转为字符串。
- **依赖声明注入**：[src/client/index.jsx:21](src/client/index.jsx#L21) 声明了 `export const inject = ["slots", "configForms", "commandUi"]`，确保 Cordis 上下文注入了所有调用的服务。
- **overlay 槽位注入**：在 [src/client/index.jsx:36-53](src/client/index.jsx#L36-L53) 中，通过 `ctx.slots.inject("conversation.input.overlay", ...)` 进行 session-scoped 注册，注入属性 `{ sessionId, scope, isOpen, subscribe, dismiss }`，仅在状态处于打开时渲染 `InjectDialog`，关闭时返回 `null`，完全符合 `conversation.input.overlay` 的设计范式。

### 2. 状态订阅与闭包风险分析
- **`dialog-state.js` 机制**：`createDialogStore` 内部通过 `Set` 管理 `open` 与 `listeners`。`emit()` 拷贝了当前监听快照 `[...listeners]` 触发回调；`subscribe` 返回精准注销函数 `() => listeners.delete(listener)`。
- **`InjectOverlay` 状态同步**：[src/client/inject-dialog.jsx:41-46](src/client/inject-dialog.jsx#L41-L46) 中，`useEffect` 依赖项包含 `[subscribe, isOpen]`。因为 `isOpen` 闭包直接调用 `dialogs.isOpen(sessionId)`，在监听器触发时调用 `isOpen()` 获取最新状态并 `setOpen`，不存在 stale-closure（陈旧闭包）问题；组件卸载或依赖重绑时返回的 cleanup 正常移除 listener，无内存泄漏风险。
- **全局清理**：`createDialogStore()` 在插件生命周期 `apply(ctx)` 中创建，所有 effect 均包裹在 `ctx.effect(...)` 中，随插件卸载自动清理。

### 3. 入口与用户体验分析
- **常驻按钮移除合理性**：注入回合主要面向调试、高级 Prompt 注入或特定预设测试，属于非高频核心路径；移去输入栏常驻按钮避免了与核心发送操作的视觉竞争。
- **命令与快捷入口可发现性**：用户在输入栏输入 `/` 即可在命令下拉菜单中看到 `/inject-turn`（含宿主注册的描述说明）；亦可通过 `/inject-turn` 直接呼出。快捷键与斜杠菜单完整保留，未丢失必要入口。
