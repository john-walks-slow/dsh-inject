# dsh-inject 检视记录

## 已修复

- volatile 配置字段与 settings auto policy，支持 Web 热更新。
- `configForms.mutate` 使用 `{ op: "set", path: [..], value }`。
- 命令改为全局注册，按 session id 管理启用预设，避免 agent 重载重复注册。
- 手动构造回合进入请求侧 pending queue，不写 session transcript。
- 系统/开发消息不参与用户规则替换；系统前缀合并保留在首位。
- 无效正则被跳过，工具模板转为带标记的用户上下文，避免孤立 tool result。

## 未纳入本轮

现场 dialog 的客户端入口需要稳定的会话命令执行服务契约，本轮保持 `/inject-turn` 命令可用，避免引入未经验证的 UI RPC。

## 验证

隔离 dsh-e2e 实例已启动，Web 设置中出现 Inject 页面；host/client 构建、语法检查和 4 项替换/角色测试通过。
